What staff do

The orange panel above the page is only drawn for signed-in staff. In this preview it is unlocked so you can see it; sign in with anything.

On the live site it needs a WordPress username and an Application Password, and the account has to be allowed to publish.

How a document is filed

One type (what kind of document it is), one to three themes (what it is about, led by the four Ps), and free keywords for places and partners.

Type and theme become the filter rows; keywords feed the search.

Sharing a document

Opening a document changes the address bar, so the link you copy opens that document directly for whoever you send it to.

Every document can also be downloaded, and the reader works on a phone.
